# Privacy Policy for DevMock Pro

**Last Updated:** July 26, 2026

## Overview
DevMock Pro is committed to protecting your privacy. This extension operates completely locally on your client machine.

## Data Collection and Usage
- **No Data Collection:** We do not collect, store, transmit, or sell any personal data, browsing history, or network traffic to any external servers.
- **Local Storage:** All user-configured mock rules and local setting states are stored strictly within your browser's local storage (`chrome.storage.local`).
- **Network Request Interception:** The network request interception feature runs entirely locally on your Chrome browser using `chrome.declarativeNetRequest`. No intercepted payload or request information leaves your device.

## Third-Party Services
We use Lemon Squeezy solely for processing software license key verifications. No browsing or usage data is ever sent to Lemon Squeezy.
