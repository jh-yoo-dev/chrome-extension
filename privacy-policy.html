Privacy Policy

This privacy policy applies to the Chrome extension "Copy Bypass Helper".

1. Information Collection

The extension does not collect, store, or transmit any personal information. It does not access browsing history, user credentials, or any form of identifiable data.

2. Purpose of the Extension

This extension only removes JavaScript-based restrictions that prevent right-clicking, text selection, copying, and pasting on websites. All functionality runs locally in the browser and is never sent externally.

3. Data Sharing and External Communication

This extension does not send or share any data with third-party services. There are no external API requests, analytics, or remote code execution.
